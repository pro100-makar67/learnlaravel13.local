## Инициализация нового проекта Laravel
## Инструкиции по модицикации файла hosts для обхода региональных ограничений Packagist
>При возникновении сетевых тайм-аутов или блокировок со стороны CDN при выполнении команд ```composer create-project```
>или ```composer install``` необходимо перенаправить трафик на валидные IP-адреса репозиториев в обход локальных
> DNS-серверов
1. Откройте конфигурационный файл по пути: ```C:\Windows\System32\drivers\etc\hosts```
2. Вставьте подготовленный блок записей в конец файла:
```text
138.199.37.232 packagist.org
138.199.37.232 repo.packagist.org
```
Либо зайдиет в настройки OSPanel, перейдите во вкладку "Файл HOSTS" и добавьте подготовленный блок записей в конец файла
### 1. Актуализация пакетного менеджера
Обновление локального исполняемого файла Composer до последней стабильной версии
``` bash 
composer self-update
```
### 2. Инициализация каркаса приложения 
Развертывание чистого скелета Laravel в текующую рабочую директорию в которой мы находимся:
```bash
composer create-project laravel/laravel .
```
Развертывание чистого скелета Laravel и создание рабочей директории
```bash
composer create-project laravel/laravel learnlaravel13.local
```
после чего необходимо перейти в директорию с проектом (если вы еще не находитесь в ней)
```bash
cd learnlaravel13.local
```

### 3. Конфигурация API-слоя
Инсталляция и автоматическая настройка пакета аутентификации (Laravel sanctum), а также генерация базовых
маррутов для работы в режиме Stateless API:

```bash
php artisan install:api
```

### 4. Экспорт конфигурации CORS
Публикация конфигурационного файла config/cors.php для управления политиками кросс-доменных запросов
(Cross-Origin Resource Sharing):
```bash
php atrisian config:publish cors
```

### 5. Инициализация символьной ссылки для Storage
Создание симлинка из публичной директории public/storage в изолированное хранилище storage/app/public для обеспчения 
контролируемого HTTP-доступа к медиафайла:
```bash
pgp artisan storage:link
```

### 6. Маршрутизация веб-сервера (Apache)
Создание или перезапись файла конфигурации .htaccess в корневой диркектории для перенаправления входящего трафика на 
фронт-контроллер public/index.php:
```apacheconf
RewriteEngine On
# Перенаправляет всех входящих HTTP-запросов в публичную директорию public/
RewriteRule ^(.*)$ public/$1 [L]
```

## Развертывание существуюшего проекта из репозитория 

### 1. клонироание и инициализация зависимостей 

Загрузка исходного кода из удаленного репозитория и установка backend-зависимостей согласно ```composer.lock```:

```bash
git clone https://github.com/pro100-makar67/learnlaravel13.git
cd learnlaravel13
composer install
```

### 2. Подготовка окружения и генерация app_key (ключа приложения)
```bash
cp .env.example .env
php artisan key:generate
```

### 3. Миграция и сидиирование базы данных
Выоплнение базовых DDL-скриптов для построения структуры таблиц с парллельным наполнением 
справочников тестовыми или системными данными (Seeders):
```bash
php artisan migrate --seed
```

## Конфигурация подключения к СУБД (.env)

Параметры интеграции с базой данных MySQL (версии 8.4) и глобальные настройки сессий в файле .env
```dotenv
# Параметры подключения к СУБД
DB_CONNECTION=mysql
DB_HOST=127.0.0.1 (либо MySQL-8.4)
DB_PORT=3306
DB_DATABASE=learnlaravel13
DB_USERNAME=root
DB_PASSWORD=
# Драйвер сессий (локальное файловое хранилище)
SESSION_DRIVER=file # (вместо database)
```
